# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/Andersseen/falcotech/security/advisories/new),
with the steps to reproduce it and its impact. You will get an answer within a few working days.

## Scope

The website and its server endpoints, in particular `POST /api/contact` (`src/server/`), and the
deployment workflow in `.github/workflows/`. Only the latest version on `main` is supported.
